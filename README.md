# 🧠 LLM Knowledge Assistant

An intelligent enterprise knowledge assistant based on LLM + RAG architecture.

## 🚀 Features

* 📚 PDF Knowledge Base
* 🔍 Semantic Retrieval with FAISS
* 🤖 LLM-powered Question Answering
* 💬 Multi-turn Conversation
* 🛠 MCP / Tool Calling Support
* 🌐 Streamlit Web UI

---

## 🏗 Architecture

User Query → Vector Retrieval → Context Augmentation → LLM Generation

---

## 🛠 Tech Stack

* Python
* Streamlit
* FAISS
* SentenceTransformer
* OpenAI Compatible API
* PyPDF

---

## 📦 Quick Start

```bash
pip install -r requirements.txt
streamlit run web.py
```
